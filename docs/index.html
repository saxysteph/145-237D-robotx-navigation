// Project Overview

The Maritime RobotX 2026 Challenge tasks teams with fielding coordinated autonomous aerial, surface, and underwater robots. Our project delivers the aerial perception and communication layer: the Jetson Orin Nano onboard the UAV detects colored buoys via a hybrid YOLO + HSV pipeline, projects pixel centroids to GPS coordinates using monocular ray projection, and transmits structured detections to a ground station over MAVLink UDP — all in real time.

Edge Detection

YOLO11n (ONNX) proposes bounding boxes. HSV thresholding classifies color within each ROI. Two-stage design is more robust than end-to-end classification on limited data.

GPS Mapping

Pixel centroids are projected to GPS lat/lon using drone altitude, heading, and camera intrinsics. Flat-earth nadir model, valid for competition environment.

MAVLink Comms

Detections transmitted as STATUSTEXT packets over UDP. Ground station decodes to JSON and logs a JSONL file for visualization and post-processing.

Visualization

Color-coded GPS dot map rendered via matplotlib. Supports live polling mode while a session is running for real-time situational awareness.

// Quick Replication

Requires: Jetson Orin Nano (already configured) + laptop on same network.

# Terminal 1 — laptop: start ground station
cd ~/Downloads/SP26/CSE237D/145-237D-robotx-navigation
source .venv-mavlink/bin/activate
python mavlink_comms/scripts/run_ground_station.py --output-jsonl fulldemo/detections.jsonl

# Terminal 2 — SSH into Jetson: start detection
ssh babydragon@192.168.55.1
GCS_IP=192.168.55.100 bash fulldemo/run_detection_jetson.sh

# Terminal 3 — laptop: visualize live
python fulldemo/visualize_detections.py fulldemo/detections.jsonl --live

Full setup instructions (fresh Jetson): Wiki → Setup & Replication
